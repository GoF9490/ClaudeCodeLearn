사용 모델: sonnet 5.5

모드: plan mode

내용:
간단한 암산을 테스트 할 수 있는 웹페이지를 만들어줘.
시작 버튼을 누르면 타이머가 실행되며, 
랜덤으로 생성된 20문제가 순차적으로 주어지고,
20문제를 모두 풀 경우 걸린 시간을 보여주고,
확인 시 맨 처음 페이지로 돌아가.
문제는 간단한 사칙연산(덧셈, 뺄셈, 곱셈, 나눗셈)으로 이루어져야 하고,
항은 최대 4개까지 쓰일 수 있으며,
각 항은 최대 세 자리수(최대 999)까지 사용 가능하며,
결과값은 다섯 자리수(최대99999)을 넘을 수 없게 해줘.
좌항에 랜덤으로 생성된 식에 대한 정답을 우항의 빈칸 입력칸에 적고,
엔터 또는 확인버튼을 누르면 정답과 비교해서,
맞을 경우 다음문제로 넘어가고,
틀릴 경우 틀렸다는 사실을 알 수 있는 피드백을 방해가 되지 않는 선에서 알려주고,
틀린 문제를 다시 풀 수 있도록 해줘.
우항의 정답은 항상 자연수가 나오도록 좌항의 문제가 작성되어야 해.
괄호는 소괄호만 사용하며, 최대 한번만 사용 가능해.
문제의 난이도는 쉬운 난이도 10개, 이후 중간 난이도7개, 어려운 난이도 3개 형태로,
너 나름의 난이도를 판별하는 규칙을 세워서 랜덤으로 만들어지게끔 해줘.
해당 프로젝트의 목적은 어디까지나 암산 연습이니까 어려운 난이도여도 너무 어렵게 하면 안돼.
디자인은 심플해도 좋으니 토큰을 절약하는 방향으로 작업해줘.

결과:
해당 환경에 Node와 브라우저 실행이 불가능해 클로드가 자체 테스트를 건너뜀.
결과물은 만족할만큼의 퀄리티.
아쉬운점은 우항의 답안 입력창에 숫자 이외의 영어나 특수문자 등도 입력이 가능했음.
암산 테스트 용이고, 우항의 결과로 자연수만 받는다는 의도대로면,
특수문자도 쓰지않는, 숫자만 입력 가능하게끔 의도파악을 할만하지 않나 생각하지만,
어쨌든 선행규칙에 그런 점을 간과한 것 또한 문제고,
그 정도의 사소함 빼면 규칙은 모두 지켜서 완성되었음.
